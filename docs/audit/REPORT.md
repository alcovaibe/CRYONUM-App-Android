## Оценка результата

Подготовлены значительные локальные исправления калькулятора, валидации подстановок,
защиты UI/PIN, разделения аналитики, контента, OCR/PDF, истории и конфигурации R8.
Это **не заключение о полной безопасности или готовности к публикации**. Production trust
anchor отсутствует; нет Firebase-конфигурации и Android-устройства. Часть выводов подтверждена
реальными JVM-тестами, часть — только кодом. Полная матрица Android/UI/производительности
не выполнена. Открытые ограничения подробно перечислены, а не отмечены как успешные проверки.

## Карта приложения

Activity/Intent-навигация с Compose UI, launcher Splash, основной экран подстановок,
отдельные калькулятор/история/результат/лекции/PDF/политика/настройки/информация/безопасность.
Расписание — заглушка. Калькулятор теперь отдельный ViewModel + чистое JVM-ядро.
Данные: SharedPreferences, security/content DataStore, локальная Room-диагностика,
внутренние файлы PDF. Внешние границы: content URI/камера/ML Kit, сайт/config,
download.cryonum.com/подписанный manifest, Firebase Analytics/Crashlytics, внешние ссылки.
WorkManager обслуживает загрузки и проверку политики. Полная карта в ARCHITECTURE.md.

## Калькулятор: доказанные исходные ошибки

| Ввод | Baseline | Исправленное ядро |
|---|---|---|
| `|-3|` | -3 | 3 |
| `2@3` | 23 | Ошибка синтаксиса |
| `200+10%` | 200.1 | 220 |
| `sin(30)`, Deg | Ошибка | ≈0.5 |
| `asin(0.5)`, Deg | Ошибка | ≈30 |
| `log(10)` | Ошибка | ≈1 |
| `-2^2` | 4 | -4 (явное проектное решение) |
| `1e-20` | 0 | Точная дробь 1/100000000000000000000 |

Исходный engine извлечён из Git и выполнен с реальным mXparser; raw лог сохранён.
Новый модуль: точные рациональные/гауссовы рациональные значения, приближённые complex
функции Apache Commons Math, контекстные проценты, степени/корни/логарифмы/тригонометрия,
полный Ans/память и canonical persistence. Display не подставляется обратно в арифметику.
Новые неопределённые владельцем правила явно названы проектными решениями CALCULATOR.md.
Независимые Fraction/cmath и cycle-parity эталоны дополняют unit-тесты. Это ограниченный
калькулятор, не CAS. Замена mXparser не объясняется выдуманной уязвимостью или лицензионным
нарушением: основные ошибки были в интеграции и Double-only модели.

## Безопасность и воспроизведения

Воспроизведено локально переполнение schema/revision исходного JSON verifier: два
регрессионных теста падают на baseline, проходят на исправленном коде. Изолированные
ключи не относятся к production. Подпись ECDSA не подделывалась. Неверные подписи, URL,
MIME/Range/длины/хеши проверены соответствующими unit-тестами; cancel — MockWebServer.

Fail-open decrypt, гонка PIN attempts, wall-clock timeout, непоследовательные UI flags,
shortcut политики и диагностические каналы подтверждены чтением кода. Их исправления
скомпилированы, но не объявлены воспроизведёнными атаками на Android. SecurityAuditTests
с реальными DataStore/Keystore подготовлен, **не запущен**. Обычное чужое приложение не
получает автоматически доступ к private storage; root-модель вынесена отдельно.

Manifest debug/release сохранены после слияния. Свои Activity кроме launcher non-exported,
FileProvider non-exported, URI sharing ограничен camera cache. SDK-компоненты с exported
оцениваются вместе с permissions; не всякий exported сервис открыт произвольному приложению.
Debug-only preview/test components отсутствуют в release. Разрешения AD_ID удалены.
PIN остаётся UI gate, не шифрованием истории/PDF. Полный dependency CVE scan не выполнен.

## Аналитика и контент

Analytics off прекращает вызовы отправки, выключает SDK collection и сбрасывает его данные;
локальные события сохраняются, Crashlytics включён отдельно. Убраны ручные breadcrumbs и
payload details, добавлены лимиты DB/файлов и backup exclusions. Реальная доставка/очереди
Firebase и upgrade overrides требуют конфигурации владельца и устройства. Crashlytics может
отправлять технические сведения даже при Analytics off; интерфейс говорит об этом прямо.

Подлинность контента не ослаблена. Пустой публичный keyring остаётся блокером. Обычные GET
трёх конфигураций и 13 PDF успешны, размеры/magic/SHA совпали с полученным manifest, но его
подпись без доверенного ключа **не подтверждена**. Поправлены строгие integer-поля,
отмена Call, mutex операций, IO hashing, сохранение конфликтной миграции и failure Worker.
Принятие политики больше не использует default4 из диалога: переход ведёт к проверенному
документу, кнопка в viewer доступна с конкретной проверенной версией. Сайт/R2/Firebase не менялись.

## Сборка и тесты

Точные команды и результаты: logs/final-verification.log, host-tests.log, differential.log,
python-tests.log; подробные JUnit/Lint/merged manifests в reports; сводка artifacts.json.
Среда в environment.json. Baseline wrapper сначала не имел сетевого доступа из JVM,
первый Gradle build использовал JRE без javac; эти провалы сохранены, не названы успехом.
Затем подготовлены JDK21, Gradle9.6.1, SDK37/BuildTools36 через доступные загрузки и проверку
checksum Gradle. Production google-services.json/подпись отсутствуют.

- Чистая сборка `-PlocalAudit=true -Pkotlin.incremental=false clean :app:assembleDebug :app:testDebugUnitTest :app:lintDebug :app:assembleRelease :app:lintRelease :app:assembleDebugAndroidTest`: **BUILD SUCCESSFUL**, 5m57s, 143 tasks (это время сборки контейнера).
- JVM Gradle: **86 тестов, 14 suites, 0 failures/errors**. Pure host: **16 тестов** (подмножество, не дополнительные86+16 уникальных тестов).
- Differential: **1500 Fraction + 500 cmath, 0 расхождений**, seed20260907. Перестановки:5040 в unit suite.
- Python migration-map: **4 теста прошли**. Baseline overflow: ожидаемые2 failures сохранены как доказательство исходного дефекта.
- Lint debug: **117 warnings, 0 errors**; release: **118 warnings, 0 errors**. Большинство — неиспользуемые ресурсы; подробные ID в artifacts.json.
- R8/resource shrinking release прошли; инструментальный APK собран, но `connectedDebugAndroidTest` не выполнялся.
- Production Firebase/signature build и поведение release APK на устройстве **не проверены**.

Во время доработки incremental Kotlin сообщил conflicting overloads при единственном
исходном объявлении PdfViewerScreen. Лог сохранён отдельно; финальная проверка проводится
после clean с -Pkotlin.incremental=false. Это диагностический workaround окружения/сборки,
не доказанная причина дефекта compiler; проектная настройка incremental глобально не менялась.

## Производительность и UI

Измерений startup/jank/CPU/RAM/GC/энергии на 1/4 ГБ нет. Приводятся размеры APK, а не
выдуманные проценты ускорения. Eager PDF bitmap-list заменён ленивым ограниченным рендером;
OCR и hashing вынесены с Main, калькулятор получает фон/отмену/ресурсные пределы.
Методика физического устройства, повторов и сохранения traces — PERFORMANCE.md.

Выполнены XML/resource key checks, сборка и Lint. TalkBack/контраст/48dp по обеим осям,
крупный шрифт, rotation/multiwindow/tablets, отказ разрешений, отсутствие camera/Play Services,
биометрия и реальные insets — не проверены на устройстве. Часть Activity по-прежнему фиксирует
ориентацию. Личные решения не объявлены требованиями Google; источники и дата сверки сохранены.

## Реестр покрытия и полнота

coverage.csv учитывает все исходные181 Git-путей и весь итоговый индекс, включая новые код,
тесты и документы. Для XML/image/JAR/текстов указаны применимые проверки и SHA, для исходников —
компиляция/статическое рассмотрение и связанные находки. Это инвентарный реестр, **не процент
построчного, семантического или тестового покрытия**. Все экраны прошли сборочные/структурные
проверки, но не каждый пользовательский маршрут воспроизведён. Непроверенное явно остаётся
открытым. В FINDINGS — 25 записей с предпосылками, источниками, последствиями и остаточными рисками.
