# Данные, диагностика и приватность

## Хранилища

| Данные | Место и формат | Защита и миграция |
|---|---|---|
| Выражения, Ans, память | calc_prefs_v2, canonical-строки и флаги | Внутренние SharedPreferences; не шифруются; исключены из backup. v1 остаётся для импорта |
| История | history_prefs, Gson JSON | До 50 записей; чтение до 256 КиБ; повреждённое содержимое даёт пустой список без удаления исходного файла |
| PIN/сессия | security_settings DataStore, Android Keystore | AES-GCM для защищённых полей; соль и PBKDF2-хеш PIN; сессия в памяти процесса |
| Лекции/политика | files/cryonum_content | Проверенные файлы, part и метаданные; сохранность после очистки cache; исключены из backup |
| Аналитика | Room analytics_db v1 | События и локальные crash reports; не шифруются, вся БД исключена из backup |
| Аварийный fallback | files/crash_reports | До 20 файлов; исключён из backup |
| Принятие политики | policy_prefs | Допускается перенос согласно XML; версия проверяется независимо от этого флага |

Схема Room не менялась, новой миграции таблиц не требуется. Для истории добавлены nullable
поля radians/complex/previousAns. Старые записи читаются; старый режим углов не восстановить.
R8 сохраняет имена Gson-моделей. Повреждённые типы отдельных SharedPreferences и восстановление
всех хранилищ после реального backup/transfer не покрыты инструментальным запуском.

PIN из четырёх цифр и 10000 итераций PBKDF2 сохранён для совместимости. Это не сильный пароль
против офлайн-перебора при компрометации Keystore/root. Экранная блокировка не шифрует историю,
лекции или диагностику. Для иной модели потребуется отдельное проектирование шифрования БД.

## Три независимых механизма

1. Переключатель разрешает отправку Firebase Analytics. На новом запуске default — false,
   автоматическая регистрация экранов отключена в manifest. При выключении вызываются
   setAnalyticsCollectionEnabled(false) и resetAnalyticsData(). При включении SDK снова собирает
   новые разрешённые события; приложение не пересылает накопленную локальную БД.
2. Локальная диагностика продолжает работать при выключенном переключателе. Сейчас явный
   источник пользовательских событий — lifecycle экранов (имя класса, opened). details
   отбрасывается, screen/action ограничены 64 символами. Формулы, фото, URI и PIN не добавляются.
3. Crashlytics в production включается независимо. В localAudit оба удалённых SDK не
   инициализируются приложением; это отдельный applicationId для локальных проверок.

Удалены ручные breadcrumbs в Crashlytics. При включённой Analytics SDK может добавлять свои
breadcrumbs; отключение не стирает уже отправленные данные и не гарантирует удаления ранее
прикреплённых breadcrumbs из незавершённого crash report. Crashlytics по-прежнему передаёт
технические данные сбоев. Сообщения исключений сторонних SDK отдельно не фильтруются нашим
локальным форматтером. Поэтому формулировка «никакие данные не передаются» неверна.

Локальный crash report содержит модель/производителя, ОС/API, RAM/диск, версию приложения,
класс исключения и до 100 stack frames, без сообщения исключения; стек ограничен 16000 символами.
Room при вставке удаляет события старше 30 дней и сверх 2000, crash reports старше 30 дней и
сверх 20. Очистка происходит при записи, а не по отдельному таймеру; для fallback-файлов действует
лимит количества, не строгий срок. SQLite-файл не обязан уменьшаться физически после DELETE.

Из merged manifest удалены разрешения AD_ID и AdServices attribution/ad ID. Это не удаляет
все Firebase-компоненты и не является доказательством отсутствия сетевого трафика.

## Что требуется проверить с реальной конфигурацией

На отдельной тестовой Firebase-конфигурации: чистая установка, auto-init до Application,
выключение с очередью offline, включение после offline, авария при обоих положениях переключателя,
содержимое DebugView/Crashlytics и трафик. В этой среде конфигурации нет: тесты не выполнены.
Сохранившийся SDK preference прежней установки может влиять на раннюю инициализацию до
Application; manifest default защищает прежде всего чистую установку. Обновление старой версии
должно войти в обязательную проверку владельца.
